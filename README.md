# MusorDropTrollTweak

Твик который тебе мозги компостирует с мусор дропом
При его рекламе, всё на экране на 25% плавно темнеет и touch screen отключается до конца видоса (рофл рекламы)
можно настроить через сколько секунд будет вылазить или кастомное видео поставить, регулеровка звука и тд.

видео хранится в репозитории video.mp4

твик поддерживает rootful, rootless, roothide

## Этот твик сделан с целью развлечения
