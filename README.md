# MusorDropTrollTweak

Твик для развлекательного видео-розыгрыша на своём jailbroken iPhone.

## Как работает

Когда твик действительно инжектирован в пользовательское приложение, после того как приложение становится активным начинается обратный отсчёт. По окончании задержки поверх приложения появляется встроенное видео.

После окончания видео overlay закрывается, touch снова доступен, и начинается **новый отсчёт** с тем же значением задержки. Если во время ожидания изменить задержку в Settings, старый таймер отменяется и новый отсчёт начинается **с нуля сразу после изменения настройки**.

## Настройки

- **Включено** — включает или выключает автоматический показ.
- **Задержка показа** — 0–60 секунд после активации приложения.
- **Громкость (%)** — 0–100% громкости аудиодорожки.
- **Путь к видео** — полный путь к собственному MP4/MOV. Пустое поле использует встроенное прозрачное видео.

Значения сохраняются в домене `com.fogboundsloth25.musordroptrolltweak`. Изменения публикуются через Darwin notification `com.fogboundsloth25.musordroptrolltweak/preferences.changed`, поэтому уже запущенный целевой процесс может немедленно сбросить countdown.

## Видео

Исходный ролик хранится как `video.mp4`. На CI зелёный фон удаляется через chroma key.

Когда macOS runner предоставляет `hevc_videotoolbox`, CI создаёт **HEVC with Alpha** MOV. Apple документирует воспроизведение HEVC с alpha через `AVPlayer`/`AVPlayerLayer`, включая прозрачную композицию поверх остальных UIKit-слоёв. При отсутствии этого encoder используется ProRes 4444 с alpha как fallback. citeturn613192search1turn613192search3turn613192search8

Кадр выводится через `AVLayerVideoGravityResizeAspectFill`: видео полностью заполняет вертикальный экран без чёрных полос, а лишние края при отличающемся aspect ratio обрезаются.

## Пакеты

GitHub Actions собирает три `.deb` в nightly pre-release:

- **rootful** — `iphoneos-arm`;
- **rootless** — `iphoneos-arm64`;
- **RootHide** — `iphoneos-arm64e`.

CI проверяет фактическое содержимое каждого пакета: ровно один PreferenceLoader entry, tweak dylib, injection filter, встроенное видео, `preinst` и отсутствие старой PreferenceBundle-схемы.

## Важно

Используйте твик только на своём устройстве и только в развлекательных целях.
