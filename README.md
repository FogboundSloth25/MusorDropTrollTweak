# MusorDropTrollTweak

Твик для развлекательного видео-розыгрыша на своём jailbroken iPhone.

При запуске пользовательского приложения после заданной задержки поверх интерфейса показывается видео. Overlay занимает весь экран через `AVPlayerLayer` с `ResizeAspectFill`, а касания блокируются до завершения воспроизведения.

## Архитектура 1.1.0

PreferenceBundle полностью удалён. Страница настроек теперь использует стандартный **PreferenceLoader extended entry**: один plist содержит `title`, `entry` и `items`. Это устраняет отдельный `PSListController` и отдельный `.bundle`, которые в предыдущей версии давали пустую страницу в Settings.

Пакет содержит один PreferenceLoader entry, tweak `.dylib`, filter plist, прозрачное видео и `preinst` для очистки остатков старых версий.

## Настройки

- `Включено` — включает или выключает твик;
- `Задержка, сек.` — 0–60 секунд;
- `Громкость` — 0–100%;
- `Кастомное видео` — полный путь к MP4/MOV.

Значения сохраняются в домене `com.fogboundsloth25.musordroptrolltweak` через стандартные CFPreferences.

## Injection

Для загрузки в приложения используется filter `com.apple.UIKit`, который предназначен для UIKit-процессов. Сам `%ctor` дополнительно отбрасывает Apple/system bundles и `.appex`, поэтому код overlay не запускается в системных приложениях.

## Пакеты

GitHub Actions собирает:

- **rootful** — `iphoneos-arm`;
- **rootless** — `iphoneos-arm64`;
- **RootHide** — `iphoneos-arm64e`.

Rootless и RootHide используют `/var/jb` через packaging scheme Theos. На jailbreak с дополнительным AppEnabler/Bootstrap-level allowlist сторонним приложениям может потребоваться разрешение на injection самого jailbreak — пакет твика не может включить это за пределами своего `.deb`.

## Видео

Исходник хранится как `video.mp4`. На CI он проходит chroma key по зелёному фону и превращается в ProRes 4444 с alpha как `video_alpha.mov`. В пакет попадает только финальный прозрачный файл.

## Почему размеры релизов были почти одинаковыми

Ранее `.deb` был около 14.6 MB почти целиком из-за одного и того же видеофайла. Изменения Objective-C/plist занимают на этом фоне очень мало, поэтому размеры отличались на считанные килобайты. В 1.1.0 PreferenceBundle удалён, так что структура пакета теперь действительно другая.

## Важно

Используйте твик только на своём устройстве и только в развлекательных целях.
