# MusorDropTrollTweak

Твик для развлекательного видео-розыгрыша на своём jailbroken iPhone.

При запуске пользовательского приложения после заданной задержки поверх интерфейса показывается видео. На время ролика экран плавно затемняется на **25%**, а все касания перехватываются до завершения видео.

## Возможности

- задержка показа видео настраивается в Settings;
- громкость видео регулируется ползунком от 0 до 100%;
- можно указать путь к своему MP4/MOV;
- дефолтное `video.mp4` при каждой сборке автоматически проходит chroma key, поэтому зелёный фон удаляется до упаковки твика;
- кастомное видео не изменяется и воспроизводится как указано пользователем;
- после окончания или ошибки воспроизведения overlay закрывается и touch снова доступен;
- настройки устанавливаются через PreferenceLoader.

## Поддерживаемые схемы

GitHub Actions собирает три `.deb` в одном nightly pre-release:

- **rootful** — `iphoneos-arm`;
- **rootless** — `iphoneos-arm64`;
- **roothide** — `iphoneos-arm64e`.

## Видео

Исходный ролик хранится в репозитории как `video.mp4`. Во время CI-сборки из него создаётся прозрачная версия `video_alpha.mov` с удалённым зелёным фоном. Эта версия помещается непосредственно в пакет.

## Важно

Этот твик сделан только для развлечения. Используйте его только на своём устройстве. Не используйте его для обмана владельца другого устройства или для установки нежелательного ПО без согласия владельца.
